# 08.10 ResNet50 固定 Shape INT8 PTQ / Integrated AutoTune 报告

## 测试配置

- 硬件：NVIDIA L4；按实验矩阵分配 GPU 0–3。
- 模型输入：静态 `data:[1,3,224,224]` FP32，输出为 `1x1000`。
- 构建：`trtexec --onnx=<model> --saveEngine=<engine> --stronglyTyped --skipInference`。
- 评测：`trtexec --loadEngine=<engine> --warmUp=1000 --duration=0 --iterations=1000 --noDataTransfers`。
- `--noDataTransfers` 排除 H2D/D2H；结果反映 engine 执行性能。
- 校准数组由 ViT FP16 数组转换为 FP32，仅保证输入兼容性；精度结论须以 ResNet 专用校准集复核。
