# ViT TensorRT 评测流程

评测日志必须使用 `.trtexec.log` 后缀，不能与 AutoTune 或量化阶段的 `.log` 同名，避免覆盖原始搜索和校准记录。

以下以 `vit.fp16` 为例；将 `model_name` 替换为实际模型名即可。

```bash
model_name=vit.fp16
onnx_path="./model_home/vit/${model_name}.onnx"
engine_path="./model_home/vit/plan/${model_name}.plan"
log_path="./model_home/vit/${model_name}.trtexec.log"
```

## 构建 engine

```bash
CUDA_VISIBLE_DEVICES=0 trtexec \
  --onnx=model.onnx \
  --saveEngine=model.engine \
  --stronglyTyped \
  --skipInference \
  > "$log_path" 2>&1
```

## 执行评测

构建成功后，追加到同一份 `.trtexec.log`：

```bash
CUDA_VISIBLE_DEVICES=0 trtexec \
  --loadEngine="$engine_path" \
  --warmUp=1000 \
  --duration=0 \
  --iterations=1000 \
  --noDataTransfers \
  >> "$log_path" 2>&1
```

## 文件约定

- AutoTune/量化原始日志：保留原名称与路径，例如 `model_home/vit/autotune-logs/` 下的日志。
- TensorRT 构建与评测日志：`model_home/vit/<模型名>.trtexec.log`。
- TensorRT engine：`model_home/vit/plan/<模型名>.plan`。

评测 `autotune_output/vit/.../optimized_final.onnx` 时，应为其单独命名，例如
`model_home/vit/vit.int8.integrated-search-s50.trtexec.log`，不要复用量化输出的日志名。
